# 💯 100 Days of Code – Frontend Development Journey 🚀

Welcome to my **100 Days of Code** challenge repository!  
This repository documents my daily progress while learning and building projects in **Frontend Development** using **HTML, CSS, JavaScript, and modern UI concepts**.

Each folder represents a lesson, concept, or mini-project completed as part of this journey.

---

## 📌 About This Challenge

The **100 Days of Code** challenge is a commitment to code **at least 1 hour every day for 100 days**.  
The main goals of this journey are:

- Build strong frontend fundamentals
- Practice consistency and discipline
- Understand real-world UI/UX design concepts
- Improve problem-solving and layout skills
- Create a public portfolio of work
